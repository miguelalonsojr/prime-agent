- Added opt-in native Rust context ledger mode (CLM). `clm.enabled` sets a default for new sessions only. `/clm on|off|status|view|restore <epoch:revision>` controls the current session; child sessions inherit the mode with separate context files.
- Added cooperative edits to the session-owned `clm/context.txt`. Validated, durable acceptance changes the model-visible projection before the next provider request. The audit keeps the original entries. Turning CLM off freezes the accepted context; re-enabling starts a new epoch from the current model context.
- Added validated copy-only CLM JSONL import through the existing import flow. Import does not transfer pending working-file edits or live Python state.
- CLM status distinguishes estimated occupancy from measured provider usage. Unknown or invalid receipts remain unknown. The cumulative 512 MiB candidate-plus-stored snapshot limit applies at admission, with equality allowed; it is not a read or reopen quota. The separate editable document limit is 32 MiB.
- CLM is experimental. Older binaries can replay the original audit; do not downgrade an active CLM session. Native AI-status roster/summarizer CLM projections are absent. The full workspace suite has no passing receipt for the final integrated tree; platform verification is limited to Linux x86_64.
