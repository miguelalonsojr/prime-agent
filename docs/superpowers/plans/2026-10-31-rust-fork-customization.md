# Rust Fork Customization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port the behavior of customization commit `45b245c96d69ee7fb097c3b9cba7fdcdd993f33c` onto exact Rust v0.10.2, before porting CLM.

**Architecture:** Keep the Rust ownership boundaries. `pa-core` owns kernel CWD and its existing model eligibility, `pa-daemon` owns supervisor/worker admission and routing, `pa-types` owns wire vocabulary, `pa-tui` owns terminal rendering and handoff, and `pa-cli` wires these owners. Reuse the upstream Python kernel and existing behavior that already satisfies a source regression.

**Tech Stack:** Rust 2021, the locked Cargo workspace, Tokio, Serde, POSIX shell, and the existing Python kernel runtime. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-31-rust-fork-customization-design.md` (owner approved 2026-10-31).

- A public cell returns an abort before its matching kernel `Done`: Task 2 proves the abort response stays prompt, no probe overlaps the cell, and stale generations emit nothing.
- A checkout or target directory contains apostrophes and the launcher runs elsewhere: Task 1 proves exact argv, caller CWD, absolute runtime binding, and old-command preservation on build/publication failure.
- A daemon advertises only part of the new capability or sends successive legacy snapshots: Task 3 proves zero unsupported writes and fresh session-CWD fallback, without blocking legacy startup.
- A locally defined Codex-compatible model is absent from the account model list: test-only Task 5 (numeric Task 9) proves registered discovery, child completion and actual provider POST with synthetic auth and no `/codex/models` request. Upfront expiry/empty-key preflight is outside this port.
