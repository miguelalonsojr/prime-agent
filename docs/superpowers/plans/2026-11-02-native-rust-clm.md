# Native Rust CLM Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Port implemented TypeScript CLM into native Rust, including validated imports into independent Rust-owned copies, as the second final local commit.

**Architecture:** Shared lossless vocabulary in pa-types; pure policies and one controller in pa-core; existing SessionManager/SessionFile remain their respective durable owners. An acknowledged journal callback binds authoritative row IDs and commits to engine/worker actions. Native tools supply verified origin and structured outcomes, while daemon/TUI expose the optional source wire contract.

**Tech Stack:** Existing Rust workspace, serde_json preserve_order, sha2, tokio, Python kernel runtime. No dependencies added.

**Spec:** `docs/superpowers/specs/2026-11-02-native-rust-clm-design.md`
